## Data Storytelling

Transform raw data into compelling narratives that drive action.

### When to Use This Skill

- Creating executive reports
- Building data presentations
- Designing analytics dashboards
- Communicating KPI results
- Presenting performance reviews

### Story Structure

#### 1. The Hook (Context)
- What's the current situation?
- Why does this matter now?
- What question are we answering?

#### 2. The Journey (Analysis)
- What does the data show?
- What patterns emerge?
- What comparisons are relevant?

#### 3. The Insight (Conclusion)
- What's the key takeaway?
- What action should follow?
- What's the impact?

### Narrative Frameworks

#### Framework 1: Problem-Solution
```
🔴 Problem: Customer churn increased 15% this quarter
📊 Evidence: Exit surveys show pricing as top concern
💡 Solution: Introduce retention discount program
📈 Expected Impact: Reduce churn by 8%
```

#### Framework 2: Before-After
```
📅 Before (Q1): Average response time 48 hours
🔧 Action: Implemented automated routing
📅 After (Q2): Average response time 12 hours
✅ Result: 75% improvement, NPS +15 points
```

#### Framework 3: Compare-Contrast
```
┌─────────────────┬──────────┬──────────┐
│ Metric          │ Team A   │ Team B   │
├─────────────────┼──────────┼──────────┤
│ Productivity    │ 95%      │ 78%      │
│ Quality Score   │ 4.2/5    │ 4.5/5    │
│ Time to Deliver │ 3 days   │ 5 days   │
└─────────────────┴──────────┴──────────┘
Insight: Team A prioritizes speed, Team B prioritizes quality
```

### Visualization Principles

#### Choose the Right Chart
```
Comparison (Categories) → Bar Chart
Trend (Time Series)     → Line Chart
Proportion (Parts)      → Pie/Donut Chart
Distribution            → Histogram
Correlation             → Scatter Plot
Ranking                 → Horizontal Bar
```

#### Visual Hierarchy
1. **Title**: Clear, action-oriented
2. **Key Number**: Large, prominent
3. **Trend Indicator**: Up/down arrow, color
4. **Context**: Comparison, target, period
5. **Details**: Supporting data on demand

### KPI Report Template

```markdown
# 绩效报告 - 2024年Q4

## 执行摘要
本季度整体绩效达成率 **92%**，较上季度提升 5%。
销售部门表现突出，研发部门需要改进。

## 关键指标

| 部门   | 目标 | 实际 | 达成率 | 趋势 |
|--------|------|------|--------|------|
| 销售部 | 100M | 115M | 115%   | ▲    |
| 研发部 | 80%  | 72%  | 90%    | ▼    |
| 运营部 | 95%  | 93%  | 98%    | →    |

## 深度分析

### 销售部超额完成原因
1. 新产品线贡献30%增量
2. 大客户续约率提升15%
3. 渠道拓展新增50家代理

### 研发部未达标原因
1. 技术债务清理占用资源
2. 关键人员流失影响进度
3. 需求变更频繁

## 建议行动

1. **销售部**: 复制成功模式到其他区域
2. **研发部**: 增加人员编制，优化需求管理流程
3. **全公司**: 建立跨部门协作机制
```

### Storytelling Best Practices

#### Do's
- Start with the insight, not the data
- Use comparisons for context
- Highlight anomalies and patterns
- Include clear call-to-action
- Tailor depth to audience

#### Don'ts
- Don't drown in data details
- Don't use jargon without explanation
- Don't present without recommendations
- Don't ignore negative findings
- Don't forget the "so what?"

### Executive Summary Format

```
📊 One-line insight (the headline)

📈 Key metric + change (the proof)

🎯 What this means (the implication)

➡️ Recommended action (the ask)
```

Example:
```
📊 Customer acquisition cost dropped 23% this quarter

📈 CAC: $45 → $35 (vs target $40)

🎯 Marketing efficiency improvements are working;
   we can scale spend while maintaining ROI

➡️ Recommend increasing Q1 marketing budget by 15%
```
